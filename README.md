How to Explore
Open the branch dropdown above the repository file list.
Select the topic you want to study.
Browse the programs and learning materials available in that branch.
Download or clone the code to run and modify the examples.
Run Locally
Install Python 3, then clone the repository using its URL:

git clone <repository-url>
Open the cloned repository:

cd <repository-folder>
Switch to a topic branch, for example:

git switch Loops
Run a Python file from that branch:

python <filename>.py
Replace the placeholders with your repository URL, folder name, and Python filename.
